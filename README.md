# Pandas & NumPy Daily Practice

Daily Jupyter practice — one NumPy function and one pandas function per day, with code, outputs and notes.

## About
I am Ayesha Saleem, a BSIT student learning AI engineering. NumPy and pandas are the data layer underneath AI work, so I am building the habit of using them every day instead of only reading about them.

## The rules
- One notebook per day: day-01.ipynb, day-02.ipynb, and so on.
- Each notebook practices one NumPy function and one pandas function on the same data, so I can compare how the two libraries work.
- Every notebook contains the code, its output, and a short note in my own words.
- I commit and push each day's notebook on the same day.

## Tools
- Python 3.12 in WSL (Ubuntu)
- Jupyter Notebook
- NumPy and pandas
